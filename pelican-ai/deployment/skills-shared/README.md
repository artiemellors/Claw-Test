# Shared Skills

Reusable skills that apply to multiple clients. When a client uses one of these
platforms, copy or symlink the skill into their deployment.

## Available Skills

Add skills here as you build them:

- (example) `cliniko/` — appointment booking for Cliniko users
- (example) `xero/` — invoice lookup for Xero users
- (example) `google-calendar/` — calendar management
